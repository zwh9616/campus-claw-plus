# 前端视觉规约：北大红与简约教学工作台

2026-11-06按组长要求补充，由小张提出、小葛审规约并实现，小张确认样板及终审。适用02及后续06/09页面；具体路由、权限和接口以各自已批准规约为准。本次只定视觉规则，不代表页面已经实现或验收。

## 1. 设计目标和参考依据

目标是**庄重、清晰、留白充足的高校教学工具**。用户进入后能立刻找到页面标题、当前班级和主要操作。用字号、对齐、间距表达层次，不靠大面积红底、堆叠卡片和装饰抢注意力。

参考检索日期：2026-11-06。下表是设计取舍，参考来源为官方公开说明；未声称已登录体验竞品或完成截图对比。

| 来源 | 借鉴点 | 在本项目怎样落地 |
| --- | --- | --- |
| [北大标识管理办公室：标准色](https://vim.pku.edu.cn/cjwt/index.htm) | 官网列出的网页色值94070A | 本项目品牌色统一为#94070A。该页面同时列出的RGB值与十六进制并不等价，本项目明确选择其十六进制值，不在实现中混用其他“北大红”近似色 |
| [Canvas：全局导航](https://community.instructure.com/en/kb/articles/662861-unknown)及[工作台](https://community.instructure.com/en/kb/articles/664620-how-do-i-use-the-dashboard) | 常用入口位置稳定，工作台集中呈现当前内容 | 桌面左导航、右主内容；02仅“工作台”“账号与班级”。不照搬其课程、日历、消息和统计入口 |
| [Moodle：Dashboard](https://docs.moodle.org/503/en/Dashboard)及[课程概览](https://docs.moodle.org/503/en/Course_overview) | 内容按任务分组，列表/概览便于浏览 | 页面采用标题、操作、正文的顺序；后续资料/作业使用清楚的列表分组，须等对应接口批准，不在02生成占位课程或假待办 |

保持CampusClawPlus自己的名称与组件；竞品仅提供信息组织参考，不复制其整页、标志、图片或代码。本轮不额外引入UI库、远程字体或图片素材。

## 2. 统一色板

实现时在同一主题文件集中定义CSS变量，组件引用变量，不各自发明颜色。下列hover/pressed/浅底等为本项目配套色，不称为北大官方完整色板。

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| --color-brand | #94070A | 品牌字标点缀、主按钮、链接、选中导航文字与标记 |
| --color-brand-hover | #790609 | 主按钮/链接悬停 |
| --color-brand-pressed | #650508 | 主按钮按下 |
| --color-brand-soft | #FAEEEE | 当前导航浅底、少量品牌强调背景；文字用brand |
| --color-page | #F7F6F3 | 全页暖白背景 |
| --color-surface | #FFFFFF | 表单、内容区域、顶栏和导航背景 |
| --color-text | #272421 | 标题和正文 |
| --color-text-muted | #68615C | 辅助信息、字段说明；不靠低透明度制造灰字 |
| --color-divider | #E7E2DD | 内容分隔线，不能作为输入框唯一可辨边界 |
| --color-control-border | #8C8580 | 白底输入框、次按钮可辨边界 |
| --color-focus | #94070A | 2px可见焦点轮廓，外留2px间隔；红底按钮外围用白色间隔 |
| --color-success / --color-warning / --color-error | #176944 / #805900 / #B42332 | 成功、警告和错误；始终配状态文字，必要时配图标 |

- 主按钮用白字红底。页面、顶栏、整条侧栏、正文区域均不用深红整块铺底；大部分画面保持暖白/白/深灰。
- 每个任务区域最多一个实心主按钮；次操作白底描边或文字按钮。账号页“退出登录”为次级操作，与切班主按钮分区；不用相同实心红按钮暗示所有动作同等重要。
- 错误有“错误说明+修正/重试动作”，不把品牌红直接当作错误含义。禁用态以原生disabled、文字/忙碌说明表达，不能仅改颜色。
- 按[WCAG文字对比说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)，项目要求所有可读正文/辅助/按钮文字对实际背景至少4.5:1；控件必要边界、焦点和状态图形至少3:1。装饰分隔线不承担控件识别。任何透明叠层、浅底或颜色变更均需重测，不能只凭色板通过。

## 3. 大气简约的具体约束

| 项目 | 规则 |
| --- | --- |
| 字体 | 系统中文无衬线字体栈，正文16px/1.6，辅助14px/1.5，区块标题20px/1.4，桌面页标题32px/1.25；移动页标题24px/1.35。表单控件文字16px，不引入花体或通篇衬线字体 |
| 层次 | 每页一个h1，区块用h2；页面标题和主要内容构成两个重点，不给所有文案加粗、上色或放大；业务页不用48px营销标题 |
| 间距 | 4/8/16/24/32/48px统一阶梯；页标题与内容24px，区块间24或32px，字段间16px；移动外边距16px，桌面32px |
| 形状 | 输入/按钮圆角8px，主要面板12px；不使用大胶囊包围全部内容。图标统一线性风格，20px，同一套来源；单独图标按钮有可访问名称 |
| 分组 | 一个独立任务一个区域；账号字段用定义列表，后续数据优先表格/列表，不把每个字段或每行都做成卡片；主内容卡片不再嵌套卡片 |
| 装饰 | 禁止渐变大背景、玻璃拟态、霓虹光晕、自动轮播、无意义插画及假趋势图。默认以细分隔线区分区域；浮层才可用轻阴影 |
| 动效 | 非必要过渡120–180ms，仅颜色/透明度；尊重prefers-reduced-motion，不使用自动闪烁、弹跳或大幅位移 |

## 4. 页面布局及线框

桌面宽度>=768px：顶栏最小64px高，内容过长时可增高；左导航200px，主内容min-width:0，正文最大1120px并居中。页面标题先于内容，主要操作放标题行末端或其对应表单末端，不漂浮在随机位置。

```text
1440px 已登录页面
┌ CampusClawPlus ─────────── 当前角色 · 班级ID ┐
│ 工作台          │ 页面标题                 │
│ 账号与班级      │ 一句必要说明             │
│                 │ ──────────────────────── │
│ 白底/选中浅红   │ 当前任务正文             │
│                 │ 对应操作与内联状态       │
└─────────────────┴──────────────────────────┘
```

- **登录页**：无应用侧栏，暖白背景；品牌、简短说明、最大400px表单单列居中。标题、用户名、密码、内联错误、登录按钮依次排列。不要左右各占半屏的大海报、假注册/找回密码按钮或自动聚焦导致移动端键盘遮挡。
- **工作台（02）**：标题、可信角色/班级摘要、当前仅开放账号与班级功能的说明、一个账号入口。不要为了填空放学习曲线、课程卡、未读数、AI建议或未来功能灰色菜单。
- **账号与班级**：账号ID/角色/当前班级ID定义列表；教师切班独立区域；退出登录放末尾次级区域。沿用已冻结的ID输入方案，不从竞品推导班级选择列表。
- **后续06/09**：复用同一导航和主题；资料/作业遵循“标题与操作→必要筛选→列表→详情”，AI界面突出会话正文与出处。具体入口和布局须各change确认，不属于02实施范围。

宽度<768px：导航改顶部常显换行，正文单列、外边距16px；不保留桌面侧栏占用窄屏，不引入隐藏唯一入口的悬停菜单。移动主操作可占满容器宽，控件触控区域至少44×44px。长ID和错误完整换行、可选可复制，不能只靠省略号/悬停提示。内容增加时允许纵向滚动，不用固定高度裁切。

```text
360px
CampusClawPlus
工作台 | 账号与班级
当前角色 · 班级ID（可换行）
页面标题
说明 / 正文（单列）
操作 / 内联状态
```

## 5. 四态和验收

加载态在原内容位置显示占位和文字，保持主要布局，不无限转圈；空态说明原因及当前真正可用的下一步；错误靠近对应动作，保留允许保留的输入；正常态只展示可信数据。02的四态、身份清理、请求截止和重试规则仍按design D2–D5执行。

先做登录页及教师账号页样板，由小张实际确认后再扩展。样板包须说明借鉴了上面哪条布局原则，并包含：

| 检查 | 通过条件 |
| --- | --- |
| 配色与层次 | 主色为#94070A且集中引用；无深蓝/湖蓝作为另一套品牌主题；主体浅色、任务层次清楚、每区域至多一个实心主操作；无禁用装饰或假业务入口 |
| 组件 | 按钮默认/悬停/按下/焦点/禁用/忙碌及输入正常/错误有一致规则；主按钮白字、次操作明确，品牌与错误用文字区分 |
| 视口 | 同一SHA的360×800和1440×900截图；另测767/768px断点及200%缩放，无页面横向滚动、重叠、固定栏遮挡或无法触达动作 |
| 内容与键盘 | 覆盖19位ID、256码点错误及四态；Tab/Shift+Tab/Enter可完成导航、登录、切班和退出；焦点可见，错误可读 |
| 对比度 | 记录前景/背景实际色、比值及检查工具；文字>=4.5:1，必要边界/焦点/图形>=3:1。不以本规约的静态色值计算冒充浏览器验收 |
| 证据 | screenshots清单含SHA、浏览器、URL、视口、状态、mock或真实来源、截图路径；样板确认记录实际审查人/结论。布局变动后重截受影响项 |

出现任一不通过项就直接修正样板，不用“整体看起来不错”替代检查。遵循审查者直接修复流程，不增加审批人；mock测试、真实登录联验、视觉验收分别留证。本次规约没有生成或批准任何运行截图。

## 6. 给实现模型的视觉提示词

> 先读取AGENTS、docs/standards/product.md、docs/standards/frontend-visual.md和02的proposal/design/spec/tasks，确认准入。采用#94070A北大红、暖白#F7F6F3、白色面板与深灰文字，做庄重、简约、留白充足的高校教学工作台。借鉴Canvas的稳定导航和Moodle的清晰内容分组，只落实当前已批准页面与冻结接口。按规约的尺寸、字号、组件和四态实现，禁止渐变海报、玻璃拟态、满屏红底、嵌套卡片及假统计/假菜单。先交登录页和教师账号页样板，提供同SHA的360/1440截图、对比度和键盘检查，等待小张样板确认再扩展。真实认证、mock和视觉证据分开；按FEF-SC-16..19验收，同提交更新共享进度。
