## Goals / Non-Goals

目标是让02及后续服务取得可信身份、班级上下文和可撤销会话，建立可迁移的MySQL持久基础。只实现00已冻结的身份HTTP接口，提供可复用的授权服务边界。本轮不实现前端、教学资源接口、自助注册、找回密码或新的改密/管理HTTP接口。

## Decisions

### D1：继承00公共边界，不另设一套接口

以下是候选00的接口快照，最终以G2机器合同为准；有差异先回00处理，再修本规约。

| 接口 | 请求凭据 / 输入 | 成功 |
| --- | --- | --- |
| GET /health | 当前公开，不加认证 | 沿用生效健康合同；数据库接入前先解决D8 |
| POST /api/v1/auth/login | JSON username 1..64、password 1..128字符 | 200 AuthSession + campus_refresh Cookie |
| GET /api/v1/auth/csrf | 有效刷新Cookie | 200 {csrf_token}，Cache-Control: no-store |
| POST /api/v1/auth/refresh | 刷新Cookie、可信Origin、X-CSRF-Token，无请求体 | 200 AuthSession，轮换刷新Cookie及CSRF |
| GET /api/v1/me | Bearer，无请求体 | 200 Principal |
| POST /api/v1/auth/logout | Bearer、刷新Cookie、可信Origin、CSRF，无请求体 | 204，清Cookie并撤销会话 |
| POST /api/v1/auth/switch-class | 同logout凭据；JSON {class_id} | 200 AuthSession，新班级上下文及刷新Cookie |

Principal严格沿用user_id、role、class_id、session_id、session_version、expires_at；AuthSession沿用access_token、token_type=Bearer、expires_in=900、principal。ID为00限定的正十进制字符串；时间为UTC RFC3339毫秒；request_id由服务端生成32位小写十六进制。字段不能自行增删，Principal.expires_at表示当前访问凭证到期时间。

业务错误使用00固定外层error/request_id，fields始终数组，01的details为null。400/401/403/404/409/413/429/503按00枚举；429携带整数Retry-After。请求JSON上限64KiB，未知字段、重复键、类型/长度错误400；传输上限可先于认证执行。除此之外先认证、再角色、再资源归属，最后执行业务输入与副作用。不以username错误、用户不存在等细节拆分登录401。

### D2：持久数据及班级身份

MySQL是身份与会话事实来源。拟建users（唯一用户名、口令散列、teacher/student、启停及security_version）、classes、class_memberships、sessions、access_credentials及auth_audit。数据表名和迁移编号由小张在实现前协调登记，本草案不占号、不选定未评审依赖。所有SQL参数绑定；账号用户名精确匹配，不静默trim/改大小写，唯一性与数据库排序规则一致；字符长度按Unicode码点计。

教师允许拥有多个有效任课班级；学生本阶段恰属一个有效班级。创建会话前从数据库确定成员关系，不能从客户端role/class_id声明造Principal。多班教师登录的初始班级取其有效班级ID数值最小者；无有效成员关系不签发会话，返回与无效凭据一致的401。后续通过已冻结switch-class切换。成员关系撤销立即阻止该班会话继续访问。

后续业务只依赖身份/授权服务接口与存储接口；业务不反向依赖HTTP。cmd/server只装配，httpserver处理协议，身份服务实现登录/刷新/撤销/授权，MySQL适配器处理持久事务。授权接口接收服务端解析的Principal及可信资源归属，不能接收客户端传来的“已授权”布尔值。

### D3：访问凭证、刷新与并发

建议采用密码学随机不透明凭证：访问/刷新各至少256位随机量，数据库仅存其摘要；session_id为128位随机量转32位小写hex。访问凭证仅由02保存在内存，有效900秒；本次不实现02存储。刷新有效期604800秒，每次有效刷新从当前时刻重新计算；不另外引入与00 expires_in=900矛盾的隐含期限。口令散列使用带独立盐的Argon2id；精确库版本、许可及参数经小张审查并在实现前冻结，不把普通SHA摘要用于口令。

刷新在一个事务内条件更新当前刷新摘要/版本并签发新访问凭证、刷新摘要及CSRF摘要；CAS只允许一个成功者。旧刷新凭证随后401，不再返回新值，不撤销成功者，不签发第二套会话；失败不增加会话或凭证行。刷新无需让同会话既有访问凭证提前失效，它们仍受900秒及服务端撤销状态约束。客户端在刷新成功后重新GET csrf；不能沿用旧CSRF。

每个受保护请求查询会话/用户版本、过期/撤销状态和当前成员关系，不能只验令牌签名。登出、改密服务操作、账号停用/安全撤销使相关访问/刷新立即无效。改密服务更新口令与security_version及撤销会话在同一事务完成；未冻结改密HTTP接口不得自行添加。班级切换原子替换上下文、递增session_version、轮换刷新及CSRF，使该会话原班级的访问/刷新立即无效；失败保持原会话可用。

### D4：Cookie、CSRF与HTTPS

campus_refresh严格HttpOnly、Secure、SameSite=Strict、Path=/api/v1/auth、Max-Age=604800，不设置Domain。登出以同名同Path属性清除。令牌与CSRF不得进入URL、日志、localStorage或sessionStorage，身份响应no-store。仅有效刷新Cookie可取得会话绑定的高熵CSRF；状态变更同时验证准确配置的可信Origin与X-CSRF-Token，默认拒绝缺失、null或不匹配Origin，不用通配CORS。

优先级：先判刷新凭证是否有效，无效401；有效Cookie但Origin/CSRF错误403。logout/switch-class还须有效Bearer且与Cookie指向同一会话；不匹配403。以上失败均不改变会话、刷新摘要或授权数据，允许单独写脱敏拒绝审计。不得为方便本地运行静默去掉Secure；实施前由小陈准备符合该合同的HTTPS运行方式，如要例外须先由00明确修订。

### D5：授权及存在性保护

角色与班级来自服务器Principal。学生调用教师动作403；用户输入其他班级、其他用户或伪造角色不能扩大权限。跨班资源与不存在资源统一404、message=资源不存在、fields=[]、details=null，除request_id外响应一致；同班学生的个人记录也必须校验owner_user_id。通过参数化服务测试与仅测试进程挂载的探针路由验收，生产路由表不得新增假资料/作业接口。

失败对比包括业务表行数与关键值、会话/凭证数及授权记录；只允许预期脱敏审计写入。依赖不可用时503，不回退匿名、空班级或允许访问。默认没有明确授权规则的动作拒绝，不能把“同班”当学生可看全班个人数据。

### D6：迁移与最小初始化

迁移必须编号、按序、带校验和与历史记录；空库安装和已有版本升级均验证，不在应用启动时静默建表。MySQL DDL可能部分生效，不能假定一次事务回滚全部DDL；失败立即非零、记下失败步骤，阻止服务启动，不标成功版本。实施前给出该迁移可执行的检查/修复/重试路径，用故障注入验证从部分状态恢复；不得删除真实业务数据来“恢复”。

初始化是受控离线入口，无公开HTTP注册接口。由运行时安全输入提供两个班、两名不同班教师、两名不同班学生及同班第二学生；可额外给一名教师第二班成员关系验证切换。样例只含占位名，不含真实口令。口令经散列再入库，输入不经可被日志/历史记录捕获的命令行参数，不回显。重复初始化识别稳定唯一键，不能重复建人/班或覆盖既有口令；关联数据插入失败事务回滚，进程非零。正式命令、输入格式及最小口令规则在2.3中冻结后提供，不能在README写未实现命令。

### D7：安全日志、依赖与防滥用

认证/授权/撤销事件只记时间、动作、结果、内部标识及request_id；禁止Authorization、Cookie、CSRF、口令/散列、配置值、正文或学生原值。全程服务端request_id关联HTTP JSON日志及脱敏审计，不暴露审计查询接口。

登录限流参数提请小张确认：按网络源及用户名的有界不可逆键计数，60秒内最多10次尝试，下一次429；不存在账号与已存在账号同规则；Retry-After为窗口剩余秒向上取整且至少1。缺省不信任任意X-Forwarded-For；代理信任方式随D8显式配置。此参数是待审选择，不声称00已冻结。使用可控时钟验证临界点、并发及窗口释放；不依赖真实等待。

## Risks / Trade-offs

服务端每次检查会话/成员关系增加数据库访问，但满足立即撤销且不引入缓存一致性旁路；优化需保留撤销判据。刷新并发失败不撤销赢家，可避免正常竞争导致用户被踢出；仍须审计异常重复且不得记录令牌。离线初始化减少公开入口，运行输入和重复执行必须有真实验收。00健康、配置与工具版本未冻结是实施阻塞，不是已批准例外。
